# 指数分析 skill

分析股票指数 / ETF 的skill。当用户询问"某指数分析""某ETF好不好/能不能买/怎么样"时，自动生成排版精美的 HTML 分析报告（编制方法、最新行情、短期/长期表现、估值、技术面、基本面、行业分布饼图、前十大成份股等）。

## 安装方法
1. 解压后得到 `指数分析` 文件夹，放入 agent 的用户技能目录（如 `<工作空间>/.user_skills/`）。
2. 重启/刷新会话后即可触发。

## 数据源依赖（重要）
本 skill 的数据源为 **Wind 金融数据**，通过运行环境的 Wind 数据连接器（MCP）取数。

- **workbuddy / 豆包工作环境**：连接器已预置，用户需打开wind连接器，并根据页面指示申请 key 或凭据；
- **其他 agent 环境**：运行时会提示"请阅读 https://aifinmarket.wind.com.cn/skill.md 安装万得金融能力"，按提示安装后即可使用；
- 未安装/未连接 Wind 连接器时，skill 会停止分析，不会用其他数据源冒充。

## 报告示例
生成 `{XX}ETF分析报告.html` 或 `{XX}指数分析报告.html`，含顶部总结（不超过30字）、小白友好的估值/技术面一句话解读等。
