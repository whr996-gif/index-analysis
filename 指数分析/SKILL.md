# 指数分析 Skill

## 触发条件
用户说出以下任意一种表述时触发：
- "分析某某指数"
- "某某指数分析"
- "看看某某指数"
- "某某指数怎么样"
- "某某指数"
- 任何包含"指数"+"分析/看看/怎么样"的表述
- **ETF产品询问**（先解析ETF跟踪指数，再对跟踪指数分析）：
  - "某某ETF好不好"
  - "某某ETF能不能买"
  - "某某ETF怎么样"
  - "某某ETF可以买吗"
  - "某某ETF值得买吗"
  - 任何包含"ETF"+"好不好/能不能买/怎么样/能不能/值得"的表述

> 如果用户只说了"沪深300"而没有明确说"分析"，请主动询问"要分析沪深300指数吗？"
> ETF询问时，分析对象是ETF**跟踪的指数**，报告标题以ETF名称为准（如"科创芯片设计ETF分析报告"）。

#### ETF→指数解析（强制）
当触发原因是ETF产品询问时，在指数歧义确认**之前**先解析ETF跟踪的指数：
1. 使用 `mcp__wind-finance__get_fund_info`，以ETF名称或代码作为 `question` 参数，查询其 **index-tracking information（跟踪指数）**。
2. 从返回结果中提取跟踪指数名称与代码，作为后续分析对象。
3. 若查询不到跟踪指数，尝试用 `mcp__wind-finance__search_funds` 定位该ETF，再查询其跟踪指数。
4. 解析成功后，**ETF名称作为报告的展示名（display_name）**，跟踪指数作为数据源继续分析。
5. 解析失败（无此ETF/无法确定跟踪指数）时，如实告知用户无法定位该ETF对应的指数。

#### 指数歧义确认规则（强制）
在调用任何数据接口前，**必须先排除名称歧义**。执行方式：
1. 使用 `mcp__wind-finance__get_index_basicinfo`，以用户提供的简称作为 `question` 参数进行搜索。
2. 检查返回结果中的指数数量：
   - **若返回 0 个结果**：告知用户未找到该指数，请核实名称后重试。
   - **若返回 1 个结果**：直接采用该指数的代码和全称，继续后续分析。
   - **若返回 2 个及以上结果**：**必须暂停分析**，向用户列出所有候选指数。
3. 对于已知易混淆简称，即使搜索结果中只有 1 个结果，也建议在开始分析前向用户确认一次。

## 分析流程

### 第一步：识别指数名称并确认
从用户输入中提取指数名称或代码，通过Wind搜索确认全称和代码。
- **ETF询问时**：先执行 [ETF→指数解析] 得到跟踪指数，ETF名称作为报告展示名；再对跟踪指数做名称确认。
- **普通指数询问时**：直接对用户输入的指数做名称确认。

### 第二步：判断是否红利类指数
自动识别：指数名称中是否包含"红利"或"银行"关键词。
- 是 → 后续查询股息率
- 否 → 跳过股息率查询

### 第三步：数据获取（按顺序调用Wind MCP）

> **前置检查（强制）**：调用任何 `mcp__wind-finance__*` 接口前，先确认当前运行环境是否挂载 Wind 数据连接器。
> - **已挂载** → 按 3.1~3.11 顺序取数。
> - **未挂载**（`mcp__wind-finance__*` 工具不可用）→ 判断当前运行环境并提示：
>   - 若当前环境为 **workbuddy 或豆包工作**：提示用户"数据连接器不可用，请连接wind数据连接器"，然后**停止分析**；
>   - 若为**其他 agent 环境**（非 workbuddy、非豆包工作）：提示用户"请阅读 https://aifinmarket.wind.com.cn/skill.md 安装万得金融能力"，然后**停止分析**；
>   - 两种情况均不得用其他数据源冒充 Wind 数据，也不得继续生成报告。

#### 3.1 获取指数基本信息
使用 `mcp__wind-finance__get_index_basicinfo`，查询：
- 指数全称、发布机构、基日、基点
- 样本空间描述
- 选样方法（用于提取聚焦方向）
- 成份股列表及权重

**聚焦方向提取**：从选样方法文字中提取"从事"后面的内容。例如选样方法为"选取科创板中从事集成电路设计的上市公司"，则聚焦方向为"集成电路设计"。使用正则 `从事([^的。，；、]+)` 匹配，取第一个匹配组。

#### 3.2 获取指数K线数据（近3年+成交额）
使用 `mcp__wind-finance__get_index_kline`，参数：
- `period`: "day"（日K）
- 取数范围：从今天倒推3年（若指数成立不足3年，取成立以来全部数据）
- 需要的字段：日期、开盘价、收盘价、最高价、最低价、**成交额**

基于K线数据计算以下节点：
- 今天（最新收盘价、最新成交额）
- 1周前（近5个交易日）
- 1月前（近20个交易日）
- 3个月前（近63个交易日）
- 1年前（近252个交易日）
- 今年年初
- 3年前（或指数成立日）

#### 3.3 计算最新行情
- **近一周涨跌幅**：`(today_close / one_week_ago_close - 1) * 100`
- **近一月涨跌幅**：`(today_close / one_month_ago_close - 1) * 100`
> **不展示最新成交额**：最新行情板块只保留近一周、近一月涨跌两张卡片，删除成交额卡片。

#### 3.4 计算指数表现（分短期和长期）

##### 3.4.1 短期表现
- **近3个月涨跌幅**：`(today_close / three_month_ago_close - 1) * 100`
- **近一年涨跌幅**：`(today_close / one_year_ago_close - 1) * 100`
- **今年以来涨跌幅**：`(today_close / year_begin_close - 1) * 100`
- **近一年最大回撤**：从近一年（约252个交易日）K线中找出峰值到谷值的最大跌幅

##### 3.4.2 长期表现
- **近三年年化收益率**：若数据覆盖≥3年，用 `((today_close / three_year_ago_close) ^ (1/3) - 1) * 100`；若不足3年，用实际数据时长计算年化并在话术中说明
- **近五年年化收益率**：数据覆盖≥4.5年时计算，否则显示"N/A"
- **近三年夏普比率**：
  - 日收益率序列：`daily_return[i] = close[i] / close[i-1] - 1`
  - 年化收益率：`mean(daily_return) * 252`
  - 年化波动率：`std(daily_return) * sqrt(252)`
  - 无风险利率：默认2.5%
  - 夏普比率：`(年化收益率 - 0.025) / 年化波动率`，保留2位小数
- **近三年最大回撤**：从全部K线数据中找出峰值到谷值的最大跌幅

#### 3.5 生成近三年行情折线图数据
- 从K线数据中提取日期和收盘价
- 数据点超过500个时均匀采样
- 生成JSON格式的labels和data数组，传给前端Chart.js渲染折线图
- 折线图使用红色渐变填充，展示指数走势

#### 3.6 获取估值数据
使用 `mcp__wind-finance__get_index_fundamentals`，查询：
- PE-TTM（市盈率，滚动12个月）
- PB（市净率）
- **PE历史分位**（优先近10年，无则近5年，再无则近3年，最后成立以来；报告中需标注实际周期）
- 股息率（仅红利类指数）

#### 3.7 技术指标分析（基于K线数据）
基于近3个月K线数据计算：
- **均线趋势**：MA5、MA20、MA60，判断多头排列/空头排列/震荡
- **量价关系**：近5日平均成交额与近20日平均成交额比
- **近期走势**：近20日涨跌幅、是否突破60日新高
- 生成一句小白友好的技术分析话术

#### 3.8 获取成分股行业信息
对成份股列表中的每只股票，使用 `mcp__wind-finance__get_stock_basicinfo` 查询：
- 股票名称、股票代码、**中证三级行业分类**

> 饼图标题必须标注"中证三级行业"。

#### 3.9 计算行业分布（仅饼图，不展示明细表格）
将成分股按中证三级行业分类，计算每个行业的权重总和。
- **只生成饼图数据**，不生成行业明细表格
- 饼图标题标注："行业分布（中证三级行业）"
- 权重小于1%的合并为"其他"

#### 3.10 提取前十大成份股
根据权重排序，取前10只成分股，表格包含：
- 排名、股票名称、股票代码、中证三级行业、权重（%）
- 前十大权重合计
> **表格不包含总市值列。**

#### 3.11 获取基本面数据（季度营收/净利同比）
使用 `mcp__wind-finance__get_index_fundamentals`，查询指数近三年每个季度的：
- **单季度营业收入同比增长率**（%）
- **单季度归属母公司股东的净利润同比增长率**（%）

查询方式：按年度分批次查询（如"查询XXX指数2024年各季度的单季度营收同比和净利同比"），取近三年共12个季度。指数发布时间较晚导致早期季度无数据时，有多少用多少，并在话术中说明。

数据用于生成**柱状图+折线图组合图**：
- 营收同比增长率 → 柱状图（左Y轴，红色）
- 净利同比增长率 → 折线图（右Y轴，橙色）

### 第四步：生成分析话术（小白友好，一句话解读）

#### 编制方法分析话术
"该指数以[基日]为基日，基点[基点]。样本空间为[样本空间描述]。聚焦方向为[聚焦方向]。简单来说，这个指数选的是[聚焦方向]相关的代表性公司，反映了该领域的整体表现。"

#### 最新行情分析话术
"最新行情方面，[指数名称]近一周[上涨/下跌][X]%，近一月[上涨/下跌][X]%。一句话解读：[短期表现强劲/短期调整中/短期走势平稳]。"

#### 短期表现分析话术
"短期表现方面，[指数名称]近3个月[上涨/下跌][X]%，近一年[上涨/下跌][X]%，今年以来[上涨/下跌][X]%，近一年最大回撤[X]%。[回撤>30%说明短期波动极大/回撤15-30%说明波动中等/回撤<15%说明走势较稳]。"

#### 长期表现分析话术
"长期表现方面，[指数名称]近三年年化[上涨/下跌][X]%，[近五年年化X%/指数成立不足5年无近五年数据]，夏普比率[X]，最大回撤[X]%。一句话解读：[夏普>1说明收益跑赢波动，性价比不错；夏普<0.5说明波动大收益低；最大回撤>30%说明曾经跌过三成，要做好心理准备]。"

#### 行业分布分析话术（按行业数量自适应）
- **1个行业**："从行业分布来看，[指数名称]集中于[行业]行业，占比[X]%。一句话解读：行业高度集中，指数涨跌完全取决于[行业]板块的整体表现。"
- **2个行业**："从行业分布来看，[指数名称]聚集于[行业1]和[行业2]两大行业，分别占比[X]%和[X]%，合计[X]%。一句话解读：行业较为集中，指数涨跌主要看这两大行业的表现。"
- **3个及以上**："从行业分布来看，[指数名称]前三大行业分别为[行业1]（[X]%）、[行业2]（[X]%）、[行业3]（[X]%），合计占比[X]%。一句话解读：[行业集中度高，涨跌主要看前几大行业/行业分散，单一行业影响小，走势更稳]。"

#### 前十大成份股分析话术
"前十大成份股合计权重为[X]%。一句话解读：[合计>50%说明龙头效应强，指数涨跌依赖大公司/合计<30%说明成分分散，单只股票影响小]。其中[龙头股票名称]以[X]%权重位居第一。"

#### 估值分析话术（强制小白解读）
"当前PE-TTM为[X]倍，处于近三年[X]%分位。一句话解读：[分位<30%说明当前估值比历史上70%的时候都便宜，安全边际较高，适合分批布局；分位30%-70%说明估值处于历史中等水平；分位>70%说明当前估值比历史上70%的时候都贵，泡沫风险较大]。[若有股息率：股息率[X]%，[>3%说明分红收益不错/<3%说明分红一般]]。"

#### 技术分析话术（强制小白解读）
基于均线、量价、走势综合判断，生成一句话：
- 多头排列+放量上涨："近期向上趋势较强，量价齐升，短期动能充足，趋势投资者可关注。"
- 空头排列+缩量下跌："近期处于下跌趋势，成交量萎缩，短期仍偏弱，建议观望等待企稳信号。"
- 均线缠绕+震荡："近期走势震荡，多空分歧较大，方向不明朗，建议等待突破后再操作。"
- 突破新高+放量："近期突破前期高点且成交量放大，上涨空间可能打开，但需注意追高风险。"
- 跌破支撑+放量："近期跌破关键支撑位且放量下跌，短期下行压力较大，注意控制仓位。"

#### 基本面分析话术（强制小白解读）
"从基本面来看，[指数名称]最新季度（[季度]）营收同比增长[X]%，[营收高速增长/较快增长/正增长/下滑]；归母净利润同比增长[X]%。趋势上，[营收增速持续提升/有所放缓/保持稳定]，[净利润增速加速增长/有所回落/保持稳定]。一句话解读：[净利润增速远超营收增速说明盈利能力大幅提升，利润弹性很大/净利润增速高于营收增速说明盈利能力在改善/净利润增速低于营收增速需关注盈利能力变化]，行业景气度较高。"
#### 总结分析话术（顶部深红框，不超过30字）
选取各模块中提示信号最强的2个正向信号拼接，**不超过30字**：
- **基本面景气**（净利同比>100%→"基本面景气度高"；30~100%→"基本面持续改善"）
- **龙头效应**（前十大权重>60%→"龙头效应明显"；40~60%→"龙头集中度较高"）
- **估值安全边际**（分位<20%→"估值安全边际高"；<40%→"估值处于历史低位"）
- **短期趋势**（多头排列+放量→"短期上行趋势较强"）
- **长期性价比**（夏普>1→"长期性价比高"）
示例：科创芯片设计指数 → "基本面景气度高，龙头效应明显"。
规则：按信号强度取前2个拼接，超过30字只保留最强1个；无正向信号时输出"市场震荡，建议观望"。

**报告命名规则（强制）**：
- **ETF询问时**：输出HTML文件命名为 `{ETF名称}分析报告.html`（如"科创芯片设计ETF分析报告.html"），顶部深红框展示名（DISPLAY_NAME）用ETF名称，指数全称写在其下方。
- **普通指数询问时**：输出HTML文件命名为 `{指数名称}分析报告.html`（如"沪深300指数分析报告.html"），顶部深红框展示名即指数名称。
- 顶部深红框内必须包含：展示名（h1）、指数代码·指数全称、总结分析（SUMMARY，不超过30字）。

**样式要求（强制）**：
1. **字体**：使用 Inter 字体（Google Fonts CDN），数字启用 `font-variant-numeric: tabular-nums` 等宽对齐，中文 fallback 到 PingFang SC / Microsoft YaHei。
2. **网格对齐**：所有指标卡片使用 CSS Grid，`grid-template-columns: repeat(auto-fit, minmax(180px, 1fr))`，确保同行卡片等高。
3. **等高卡片**：`.metric-card` 设置 `display: flex; flex-direction: column; justify-content: center; min-height: 112px;`。
4. **表格/图表容器统一**：`.data-table` 和 `.chart-container` 统一 `border-radius: 12px`、统一内边距、统一背景。
5. **防内容撑破**：长文本使用 `text-overflow: ellipsis`，表格容器 `overflow-x: auto`，指标数值 `word-break: break-all`。
6. **加载图标**：Chart.js 图表初始化前显示 CSS spinner 加载动画，图表渲染完成后隐藏。
7. **配色**：暖米白背景 + 深红色强调，涨用红色 `#DC143C`，跌用绿色 `#228B22`。
8. **响应式**：支持移动端浏览，小屏卡片自动换列。
9. **折线图**：使用Chart.js line类型，红色渐变填充，平滑曲线(tension:0.3)，hover显示点位tooltip。
10. **基本面组合图**：使用Chart.js混合图表，营收同比为柱状图(bar，左Y轴，红色)，净利同比为折线图(line，右Y轴，橙色)，双Y轴独立刻度，hover同时显示两个指标。

## 注意事项
1. **数据时效性**：Wind数据有延迟，报告中需注明数据截止日期
2. **行业分类说明**：饼图标题必须标注"中证三级行业"
3. **红利类判定**：名称含"红利"或"银行"的指数自动查询股息率
4. **指数成立不足3年**："近三年"数据实际为成立以来，需在长期表现话术中说明；近五年数据显示"N/A"
5. **聚焦方向提取**：从选样方法中"从事"后面提取，若提取失败则用选样方法前20字
6. **行业描述自适应**：1个行业用"集中于"，2个行业用"聚集于...和..."，3个及以上用"前三大行业分别为"
7. **ETF触发**：用户询问ETF好不好/能不能买/怎么样时，先解析ETF跟踪指数再分析；ETF名称作为报告展示名，报告命名为"{ETF名称}分析报告.html"
8. **夏普比率**：无风险利率默认2.5%，若波动率为0显示"N/A"
9. **估值分位**：优先使用接口直接返回的近10年分位数据；若不支持近10年则用近5年，再无则近3年，最后用成立以来；报告中必须标注实际使用的分位周期
10. **小白解读强制要求**：估值分析和技术分析模块必须包含一句大白话解读
11. **基本面数据**：使用 `get_index_fundamentals` 按年度分批次查询单季度营收同比和净利同比，取近三年；指数发布晚导致早期无数据时，有多少用多少并在话术中说明
12. **基本面组合图**：营收同比用柱状图(左Y轴)，净利同比用折线图(右Y轴)，双Y轴独立刻度
13. **总结分析**：顶部深红框内总结不超过30字，选取信号最强的模块（基本面景气/龙头效应/估值安全边际/短期趋势/长期性价比），自动生成
14. **最新行情**：只保留近一周、近一月涨跌卡片，**不展示成交额**
15. **连接器不可用处理**：未挂载 Wind 连接器时，先判断运行环境：**workbuddy 或豆包工作**环境提示"数据连接器不可用，请连接wind数据连接器"；**其他 agent 环境**提示"请阅读 https://aifinmarket.wind.com.cn/skill.md 安装万得金融能力"；两种情况均停止分析，不得用其他数据源代替
