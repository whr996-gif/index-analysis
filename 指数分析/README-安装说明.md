# 指数分析 Skill 安装说明

## 一、这是什么
一个用于分析股票指数 / ETF 的豆包工作 agent 技能。当用户询问"某指数分析""某ETF好不好/能不能买/怎么样"等时，自动生成一份排版精美的 HTML 分析报告，包含：

- 编制方法（基日、样本空间、聚焦方向）
- 最新行情（近一周、近一月涨跌）
- 指数表现（短期：近3月/近1年/今年以来/近1年最大回撤；长期：近3年年化/近5年年化/近3年夏普/近3年最大回撤）+ 近三年行情折线图
- 估值分析（PE-TTM、估值分位，优先近10年其次近5年）+ 小白解读
- 技术指标分析 + 小白解读
- 基本面分析（近三年季度营收/净利同比组合图）
- 行业分布（中证三级行业饼图）
- 前十大成份股（含权重、无总市值）
- 顶部深红框总结（不超过30字）

## 二、安装方法
1. 将本 zip 解压，得到 `指数分析` 文件夹（内含 SKILL.md、assets/、references/、scripts/）。
2. 将 `指数分析` 文件夹放入豆包工作 agent 的用户技能目录（user_skills）即可，例如：`<工作空间>/.user_skills/指数分析`。
3. 安装后重启/刷新会话，即可触发。

## 三、数据源依赖（重要）
本 skill 的数据源为 **Wind 金融数据**，通过运行环境预置的 **Wind 数据连接器**（MCP，`mcp__wind-finance__*` 系列接口）取数。

- 使用本 skill 前，请确认当前豆包工作 agent 运行环境已挂载 Wind 数据连接器。
- 若未挂载，skill 会提示："数据连接器不可用，请连接wind数据连接器"，并停止分析。
- 用户无需申请或提供任何 key / 账号 / 凭据，数据访问由平台侧接入的 Wind 服务提供。

## 四、版本记录
- 支持 ETF 产品询问 → 自动解析跟踪指数分析
- 报告命名：`{XX}ETF分析报告.html` 或 `{XX}指数分析报告.html`
- 最新行情不展示成交额；行业分布仅饼图（中证三级行业）；前十大成份股无总市值列
- 估值分位优先近10年，无则近5年
- 未挂载 Wind 连接器时提示"数据连接器不可用，请连接wind数据连接器"
